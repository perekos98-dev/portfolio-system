# Button (кнопка)

Кнопка запускає дію: надіслати форму, відкрити проєкт, написати мені. Є два варіанти (основна й другорядна), два розміри та стани default, hover, focus і disabled.

## Параметри

- `variant`: `primary` або `secondary`. За замовчуванням `primary`.
- `size`: `md` (звичайний) або `lg` (великий). За замовчуванням `md`.
- `disabled`: `true` або `false`. За замовчуванням `false`.
- `disabledReason`: текст пояснення під вимкненою кнопкою. За замовчуванням не задано.
- Інші атрибути: усі стандартні атрибути `button` (`onClick`, `type`, `aria-*`). `type` за замовчуванням `button`.

## Варіанти і стани

- **primary**: заливка `accent`, текст `canvas`. Контраст тексту 5,59:1 (потрібно не менше 4,5:1).
- **secondary**: без заливки, межа `ink-muted` (контраст не менше 3:1), текст `ink`.
- **hover**: primary темнішає до `ink`; secondary отримує підкладку `accent-soft`.
- **focus** (клавіша Tab): чіткий контур кольору `ink` з відступом від кнопки. Добре видно і на сторінці, і на кнопці.
- **disabled**: підкладка `surface`, текст `ink-muted`, без видимої межі (вона збігається з підкладкою `surface`), курсор «заборонено». Кнопка робиться через `aria-disabled`, а не атрибут `disabled`, тому лишається у фокусі, а клік нічого не робить. Пояснення з `disabledReason` стоїть під кнопкою й зв'язане з нею через `aria-describedby`.

## Токени

- Кольори: `accent`, `accent-soft`, `canvas`, `ink`, `ink-muted`, `surface`.
- Шрифт: `font-sans`. Розміри тексту: `text-button` (звичайна), `text-lead` (велика), `text-caption` (пояснення).
- Радіус: `rounded-control`.
- Відступи: звичайна `px-6 py-3`, велика `px-8 py-4`, проміжок до пояснення `gap-2`.

## Коли використовувати

- Основну кнопку — для головної дії на екрані. Краще одна на екран.
- Другорядну — для додаткових дій поруч з основною.
- Вимкнену — коли дія тимчасово недоступна; завжди додавай `disabledReason`.
- Для переходу на іншу сторінку краще посилання, а не кнопка.

## Як брати в код

```tsx
import { Button } from "@/components/Button";

<Button>Написати мені</Button>

<Button variant="secondary" size="lg">Мої роботи</Button>

<Button disabled disabledReason="Заповніть форму, щоб надіслати.">
  Надіслати
</Button>
```
