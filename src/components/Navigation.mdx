# Navigation (навігація)

Пункти меню сайту: головна, роботи, про мене, контакти. На широкому екрані пункти стоять у рядок, на вузькому меню згортається в кнопку «Меню». Є стани default, hover, focus і активний пункт.

## Параметри

- `items`: список пунктів, кожен має `label` (текст) і `href` (адреса). Обов'язковий.
- `active`: `href` активного пункту, тобто поточної сторінки. За замовчуванням не задано, тоді активного пункту немає.
- `label`: підпис навігації для скрінрідерів. За замовчуванням «Основна навігація».

## Варіанти і стани

- **default**: текст `ink-muted`, без підкладки.
- **hover**: підкладка `accent-soft`, текст `ink`.
- **focus** (клавіша Tab): чіткий контур кольору `ink` з відступом від пункту. Контраст контуру з тлом не менше 3:1.
- **активний пункт**: підкладка `accent`, текст `canvas` (контраст 5,6:1), на пункті стоїть `aria-current="page"`. При наведенні підкладка темнішає до `ink`.
- **вузький екран** (менше 768 px): меню згорнуте в кнопку «Меню» (вона `secondary`, з `aria-expanded`). Відкрите меню показується поверх контенту: сторінка не зсувається вниз. Закривається клавішею Escape (фокус повертається на кнопку), повторним натисканням на кнопку або вибором пункту.

Щоб побачити вузький екран, у тулбарі Storybook відкрий Viewport і вибери мобільний розмір. У вкладці Docs меню показано в рамці на повну ширину, тож вузький екран дивись на сторінці самої історії.

## Токени

- Кольори: `accent`, `accent-soft`, `canvas`, `ink`, `ink-muted`, `line`.
- Шрифт: `font-sans`. Розмір тексту: `text-button`.
- Радіуси: `rounded-control` (пункти), `rounded-card` (відкрите меню на вузькому екрані).
- Відступи: пункт `px-4 py-2`, проміжок між пунктами `gap-2`, внутрішній відступ відкритого меню `p-4`, відстань від кнопки до меню `mt-2`.

## Коли використовувати

- Одну навігацію в шапці сайту, на кожній сторінці.
- Активним став пункт, що відповідає поточній сторінці; одночасно активний лише один.
- Не для дій: дію (надіслати, відкрити) краще робити кнопкою `Button`.
- Пунктів має бути небагато (до п'яти-шести), інакше в рядок вони не вмістяться.

## Як брати в код

```tsx
import { Navigation } from "@/components/Navigation";

const items = [
  { label: "Головна", href: "/" },
  { label: "Роботи", href: "/projects" },
  { label: "Про мене", href: "/about" },
];

<Navigation items={items} active="/projects" />
```
