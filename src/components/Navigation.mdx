# Navigation (навігація)

Пункти меню сайту: головна, роботи, про мене, контакти. На широкому екрані пункти стоять у рядок, на вузькому меню згортається в кнопку «Меню». Є стани default, hover, focus і активний пункт.

## Параметри

- `items`: список пунктів, кожен має `label` (текст) і `href` (адреса). Обов'язковий.
- `active`: `href` активного пункту, тобто поточної сторінки. За замовчуванням не задано, тоді активного пункту немає.
- `label`: підпис навігації для скрінрідерів. За замовчуванням «Основна навігація».
- `menuLabel`: текст кнопки на вузькому екрані, коли меню закрите. За замовчуванням «Меню».
- `closeLabel`: текст кнопки на вузькому екрані, коли меню відкрите. За замовчуванням «Закрити».

## Варіанти і стани

- **default**: текст `ink`, без підкладки.
- **hover**: підкладка `accent-soft`.
- **focus** (клавіша Tab): чіткий контур кольору `ink` з відступом від пункту. Контур добре помітний на тлі.
- **активний пункт**: текст `accent` (достатній контраст на `canvas`) з підкресленням, без заливки; на пункті стоїть `aria-current="page"`. При наведенні з'являється підкладка `accent-soft`.
- **вузький екран** (нижче брейкпоінта `md`): меню згорнуте в кнопку «Меню» (вона `secondary`, з `aria-expanded`). Відкрите меню — панель на всю ширину найближчого батька з `position: relative` (на сайті це шапка, тобто від лівого до правого краю контенту), під ним, поверх контенту (`z-20`), без зсуву сторінки. Фон `canvas`, межа `line`, кути `rounded-card`. Пункти — рівні рядки на всю ширину: текст `text-lead` звичайної жирності кольору `ink`, вирівняний ліворуч, відступи `px-4 py-4`, між рядками тонкі роздільники `line`. Увесь рядок клікабельний, а його висота більша за мінімальну для натискання пальцем. Активний пункт, як і на десктопі, `accent` з підкресленням. Закривається клавішею Escape (фокус повертається на кнопку), повторним натисканням на кнопку або вибором пункту.

Батько навігації на вузькому екрані має бути `relative`, інакше панель позиціонується від іншого предка. У Storybook це робить декоратор історії.

Щоб побачити вузький екран, у тулбарі Storybook відкрий Viewport і вибери мобільний розмір. У вкладці Docs меню показано в рамці на повну ширину, тож вузький екран дивись на сторінці самої історії.

## Токени

- Кольори: `accent`, `accent-soft`, `canvas`, `ink`, `line`.
- Шрифт: `font-sans`. Розмір тексту пунктів: `text-lead`, звичайна жирність; кнопка «Меню» — `text-button` (з `Button`).
- Радіуси: `rounded-control` (пункти на десктопі), `rounded-card` (панель відкритого меню на вузькому екрані).
- Відступи: на десктопі пункт `px-4 py-2`, проміжок між пунктами `gap-2`; на вузькому екрані рядок `px-4 py-4`, відстань від шапки до панелі `mt-2`.

## Коли використовувати

- Одну навігацію в шапці сайту, на кожній сторінці.
- Активним став пункт, що відповідає поточній сторінці; одночасно активний лише один.
- Не для дій: дію (надіслати, відкрити) краще робити кнопкою `Button`.
- Пунктів має бути небагато (до п'яти-шести), інакше в рядок вони не вмістяться.

## Як брати в код

```tsx
import { Navigation } from "@/components/Navigation";

const items = [
  { label: "Головна", href: "/" },
  { label: "Роботи", href: "/projects" },
  { label: "Про мене", href: "/about" },
];

<Navigation items={items} active="/projects" />
```
