# LabelList (рядок міток)

Короткі підписи в один рядок, між якими стоїть крапка кольору `accent`. Підходить, щоб перелічити напрями роботи чи теми. На вузькому екрані підписи переносяться на новий рядок.

<Canvas of={LabelListStories.Playground} />

<Controls of={LabelListStories.Playground} />

## Параметри

- `items`: список підписів у порядку показу. Обов'язковий. Крапка стоїть лише між сусідніми підписами.
- `label`: підпис списку для скрінрідерів. За замовчуванням не задано.

## Варіанти і стани

Станів немає: це не інтерактивний елемент. Підписи не клікаються. Крапки декоративні й для скрінрідерів приховані, тож список читається як звичайний.

## Токени

- Кольори: `ink` (текст), `accent` (крапки).
- Шрифт: `font-sans`. Розмір тексту: `text-caption`.
- Радіус: `rounded-control` (крапка).
- Відступи: крапка `size-2`, поля навколо неї `mx-3` (на вузькому екрані `mx-2`, щоб три мітки вміщалися в один рядок).

## Коли використовувати

- Для переліку двох-п'яти коротких підписів під заголовком чи абзацом.
- Не для навігації й не для кнопок: підписи не клікаються.
- Не для довгих фраз: у рядку вони погано читаються.

## Як брати в код

```tsx
import { LabelList } from "@/components/LabelList";

<LabelList items={["WEBSITES", "WEB SERVICES", "MOBILE APPS"]} />
```
